# THE WORDS THIS CODEBASE'S NAMES ARE BUILT FROM.
#
# A guard that asks « is this word French? » can only be as good as its list of
# French words, and that list had holes: `suivante`, `trier`, `fermer`,
# `afficher`, `chargement`, `compte` and `monde` were all invisible to it, so
# « no violation » quietly meant « none among the words we thought of ».
#
# This asks the opposite question — « is this word one we use? » — and that one
# has no holes by construction. A name built from a word nobody has written
# down is refused, whatever language it comes from.
#
# ADDING A WORD IS THE POINT, not a chore. One line, in sorted order, and the
# reviewer sees the vocabulary grow by exactly what the change needed. A word
# that arrives here in French is a decision someone had to type out.
#
# Seeded from the codebase on the day the engine's identifiers became English.
# ── THE DESIGN VOCABULARY ──────────────────────────────────────────────
# Seeded from identifiers, this list had never met a STYLESHEET: arm 14
# reads custom-property names, and sixty-six ordinary English design words
# — background, muted, radius, tracking, the size scale — were unknown to
# it. They are merged into the list above rather than kept apart, because they
# are words this codebase uses like any other.
#
# « NONE OF THEM WAS FRENCH » WOULD BE FALSE, and an adversarial review said
# so: `accent`, `border`, `danger`, `data`, `font`, `modal`, `motion`, `normal`,
# `radius`, `ring`, `signal` and more are French words too. That is not an
# objection — it is the whole reason this file asks « is this a word we use? »
# rather than « is this French? ». A word here is licensed because this
# codebase writes it, not because some dictionary failed to recognise it.
#
# It IS a widening, and a deliberate one: these words are now accepted by every
# arm that reads this list, not only by the stylesheet arm that needed them.
# That is correct for design vocabulary — a `data-danger` attribute or a
# `radius` identifier is good English anywhere in this repository — but it is
# written down here so the next reader knows it was a decision.

# Everything above is English. Everything below is NOT, and saying so is
# the whole point of the line: the first version of this file was SEEDED
# from the codebase, so the twenty-four French words that twenty-nine
# names still needed came in with the rest and the gate went green over
# them. A vocabulary that certifies the status quo answers no question.
#
# They are needed by exactly ONE file — `frontend/maquette/design/src/
# engine/legacy.js`, the 35 000-line fragment SP4-fin dismantles — and
# `check_french_debt` refuses them anywhere else, so the debt cannot
# spread while it waits. Measured, not assumed: removing all of them
# reports twenty-nine names, every one in that file.
#
# When the engine goes, this section goes with it, and the arm that
# guards it says so by finding nothing left to guard.
