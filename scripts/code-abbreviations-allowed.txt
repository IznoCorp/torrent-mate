# WORDS THAT ARE NOT ABBREVIATIONS — considered, and kept, each with why.
#
# A word here may never join `scripts/code-abbreviations.txt`; the guard
# refuses the contradiction rather than letting one file quietly win.
#
# Format: `word = the reason it stays`. A LINE WITH NO REASON IS ITSELF A
# VIOLATION — the same discipline `french-ok:` is held to. An exemption nobody
# had to justify is indistinguishable from an oversight, which is how 842
# interface strings once sat under a green gate.

# ── Language conventions ─────────────────────────────────────────────────────
self = the instance parameter; renaming it fights the language, not the reader
cls = the class parameter of a classmethod, for the same reason as `self`
args = the positional-catchall's name, fixed by the language
kwargs = the keyword-catchall's name, fixed by the language
argv = the interpreter's own name for the command line
str = a built-in type, not a shortened `string`
dict = a built-in type, not a shortened `dictionary`
int = a built-in type, and nobody reads it as a shortened `integer`
repr = a dunder's name, `__repr__`, fixed by the language
init = `__init__`, and the initialiser it names everywhere else
enum = the standard library's own name for the module and the class
exc = the STANDARD LIBRARY's own spelling — `sys.exc_info`, `exc_type`, `exc_value`, and `except … as exc` in the language's own documentation. 544 occurrences here, and refusing it would fight the language rather than the reader. The most-carried word in this file, so it is named with its count
min = a built-in, and the word every reader of any language already holds
max = a built-in, on the same ground as `min`

# ── And one that is neither, kept on evidence ────────────────────────────────
dir = a TYPE SUFFIX and never a bare name — measured over the whole repository, it is always the tail of a longer name (`media_dir`, `staging_dir`, `_walk_dir`), and a suffix that qualifies a noun reads without a translation. `media_directory` buys nothing for four more characters.
