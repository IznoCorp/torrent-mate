# The reader's office — what holds for every review round

Every review round's launch brief CITES this file instead of copying it, and carries only what is
the round's own: the two worktrees (candidate, control), the lot under review, its lens, the
measured points owed in the report, and any amendment — which names the line of this file it
overrides. Story: `docs/reference/frontend-steward.md` § « The adversarial review is INDEPENDENT
of the author ».

## The permanent lenses

Each one line, its order number, and a pointer to its source: `docs/reference/operator-method.md`,
rules table, the row named — or its archive `docs/reference/operator-method.md@5a763b90a` for the
dated journal before 2026-09-12.

- **The operator's path, at every width, order 85** (replaces order 60): every surface the lot
  touched is walked by FINGER on tm-design, at 320, 360, 369, 390, 412, 768 and 1280 px, from a
  COLD start AND from the previous state (arriving from where a user comes from), with frames
  sampled in time (what is painted at 0, 100, 300, 1000 ms — not only the final state), and the
  neighbours of every repair. No truncation, no horizontal overflow, no element cut at any of the
  seven widths (`docs/reference/operator-method.md`, rules table, row « ordre 85 »).
- **No merge with a visible major, order 62**: a product MAJOR found in the walk is flagged as
  such — it blocks the merge without the operator's word (row « ordre 62 »).
- **Mutations, order 66**: replay TEN claimed mutations drawn AT RANDOM (the draw's seed and list
  said) through `mutate.sh` on the final head, not all of them; more than one of the ten not
  falling replays them all. Spend the time saved on the round's own mutations of the lot's new
  behaviours, each read by name (row « ordre 66 »).
- **Case exhaustiveness, order 77**: every case of each surface the lot touched is a named state of
  the catalogue the operator opens on tm-design; the round inventories the surfaces' missing cases
  (row « ordres 76, 77 »).
- **Design-system coherence, order 79**: every new element maps to a component of
  `design/src/ui/` (an element → component table in the DESIGN), or its novelty is justified;
  redrawing the existing is a defect (row « ordre 79 »).
- **Navigation paths, order 81**: every navigation path walked by finger against constitution § 16
  as amended by #635; every departure from it is filed as a defect (row « ordre 81 »).
- **Behaviour uniformity** (operator, 2026-09-29 22:2x, verbatim: « Il faut uniformiser les
  comportements. Sauf exception volontaire de ma part. »): one element, one behaviour, across every
  surface it appears on; an exception is never assumed — only the operator declares one
  (`docs/reference/operator-method.md` § 1, the principles table).

A ruling is not a finding; a figure that contradicts the round's own measurement IS. What is
already known — a prior round's RULINGS, a filed register row of a family this round is not
opening — is read, never re-found as a finding.
